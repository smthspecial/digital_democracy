## Finding

Severity: **Critical**. Assessment: **SEC-01**.

Anonymous HTTP requests created, opened, issued tokens for a nonexistent citizen, cast with an invalid bearer, tallied and certified a vote in both memory and Postgres. Arbitrary non-option choice data became the winner.

## Evidence

See [security report](../../../testing/security/REPORT.md) and its sanitized
memory/Postgres result files. Source locations, fixtures and scope limits are
recorded there. Run [TP-016](../../technical/test-plans/tp-016.md) for reproduction.

## Required correction

Authenticate allow-listed system callers for lifecycle and issuance; enforce the specified citizen assurance/proof boundary for casting without breaking ballot secrecy. Complete TASK-005 eligibility derivation and validate ballot contents.

## Verification

Voting lifecycle and issuance require signed api-ts requests. Casting validates a real T3 citizen, token ownership and an independent ballot proof. Eligibility is resolved from verified jurisdiction rules, ballot records use unrelated random references, and tally rejects choices outside frozen options. Missing cryptographic integration fails closed; production proof/decryption prerequisites are documented in ADR-041.

See [remediation](../../../testing/security/REMEDIATION.md) and
[final verification](../../../testing/security/remediation-validation.json) for
regression results, positive controls and deployment limits.
