## Finding

Assessment SEC-10: the same signed request was accepted twice inside the
five-minute timestamp window. ADR-040 explicitly described this limitation.

## Correction

Require a random nonce, bind producer identity and the query string into signed
bytes, and consume signatures once. Both runtimes use persistent unique replay
records with restricted worker access. The old signing format fails closed.

## Verification

Go and TS replay regressions, cross-instance Postgres consumption, and the local
memory/Postgres penetration runner reject repeated signatures and producer
substitution. See `testing/security/remediation-validation.json`.
