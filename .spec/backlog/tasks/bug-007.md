## Finding

Severity: **High**. Assessment: **SEC-03**.

Anonymous creation impersonated an arbitrary delegator. Revocation with no X-Citizen-ID succeeded in memory and Postgres. A fixture supplied active competency; that check did not establish delegator consent. Static construction defaults to allow-all competency when unconfigured.

## Evidence

See [security report](../../../testing/security/REPORT.md) and its sanitized
memory/Postgres result files. Source locations, fixtures and scope limits are
recorded there. Run [TP-016](../../technical/test-plans/tp-016.md) for reproduction.

## Required correction

Require validated T2 citizen context and active citizenship; bind creation and revocation to the delegator, reject missing identity, and fail closed on missing competency configuration.

## Verification

Delegation writes use validated T2 citizen context. Create and revoke enforce ownership, forged citizen headers are ignored, and unavailable competency verification denies creation.

See [remediation](../../../testing/security/REMEDIATION.md) and
[final verification](../../../testing/security/remediation-validation.json) for
regression results, positive controls and deployment limits.
