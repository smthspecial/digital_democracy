## Finding

Static inspection of the mesh template found that its gateway GET rule covered
the four TypeScript signed worker reads. Application HMAC guards still deny
anonymous access, but this broad rule cannot establish the intended binding
between the claimed producer and its workload principal for those reads.

## Fix and remaining validation

The gateway GET rule now excludes duplicate scanning, registration burst checks,
eligible-citizen rosters and authoritative protocol-approval reads. Trusted
api-go workload access retains producer-header binding. Variable segments use
Istio URI-template operators rather than unsupported middle glob syntax.

The rendered exclusion check passes. Live gateway denial, trusted positive
controls and path-normalization attempts remain pending because TASK-013's
local cluster cannot start its network layer. Keep this ticket in testing until
that workload-boundary evidence is recorded; no production deployment occurred.
