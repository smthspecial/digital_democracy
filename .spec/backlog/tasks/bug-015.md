## Finding

Exact-image Trivy scans found eight HIGH npm dependency findings in the Node
base image's `/usr/local/lib/node_modules/npm`, despite the workspace advisory
gate passing with its three locally patched exceptions. The Go runtime also
used end-of-life Alpine 3.20. A zero reachable Go advisory scan did not detect
the unsupported operating-system boundary.

The Prisma migration image additionally retained the build stage's Corepack
pnpm cache with HIGH/CRITICAL tool dependencies. Remove that cache from the
migration stage too; it is not needed by the direct Node Prisma invocation.
Update the build-tool pin from pnpm 10.29.3 to published pnpm 10.34.6, beyond
the scanner's 10.34.5 fixes, rather than continuing to build with the vulnerable
manager. Keep the workspace lockfile unchanged unless resolution requires it.

## Remediation

Use supported Alpine 3.24.2 for Go. Upgrade Alpine packages during image builds.
Remove unused npm/Corepack/Yarn executables and libraries from final Node
runtime and migration images; migrations invoke their retained Prisma CLI with
node directly. Retain package managers in build stages only. CI scans all four
artifacts and rejects HIGH/CRITICAL findings and unsupported operating systems.

## Acceptance criteria

- [x] Rebuild and scan all four exact artifacts; record raw reports and identities.
- [x] Verify runtime startup/non-root execution and separate Prisma migration
  execution after removing package managers.
- [x] Preserve the workspace exception register; image cleanup is not an
  upstream fix for mobile build-tool dependencies.
