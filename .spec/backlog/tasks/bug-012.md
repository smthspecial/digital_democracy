## Finding

Severity: **High**. Assessment: **SEC-08**.

The advisory snapshot contains 98 distinct npm advisories (7 critical). govulncheck selecting Go 1.25.0 finds 29 advisories on callable paths, including 27 in the standard library plus pgx and x/text. Conditional exploit prerequisites and runtime/tooling distinctions are documented; no advisory exploit was attempted.

## Evidence

See [security report](../../../testing/security/REPORT.md) and its sanitized
memory/Postgres result files. Source locations, fixtures and scope limits are
recorded there. Run [TP-016](../../technical/test-plans/tp-016.md) for reproduction.

## Required correction

Upgrade compatible maintained patched packages/toolchains, including pgx >=5.9.2 and x/text >=0.41.0. Triage feature/platform-dependent npm advisories, update Next and tooling, rerun scans and relevant tests.

## Verification

Updated maintained runtime/tooling dependencies and Go 1.27.1. Three no-published-fix npm dependencies have reproducible pnpm patches, ten exploit regressions and an exact-advisory CI gate. Raw version-based audit still reports those three; Go reports zero imported/reachable vulnerabilities and one unused OpenPGP module notice. See the retained scanner snapshots.
