## Finding

Helm template's namespace option does not insert metadata.namespace into
templates that omit it. The combined runtime bundle would therefore apply into
kubectl's default namespace instead of the two intended runtime namespaces.
That breaks Secret resolution, workload principals, routes and rollout waits.
The coordinator has not been executed against any real target.

## Fix and verification

- [x] Add explicit Release.Namespace to every namespaced chart resource.
- [x] Render the combined bundle and verify every resource's namespace,
  deployment identity and matching release/image digest.
- [x] Recheck chart lint and existing infrastructure/release safeguards.

[Offline render evidence](../../../testing/production-readiness/release-render-results.json)
covers all 18 resources in the two runtime namespaces. Both chart lint runs,
bundle integrity/privacy validation, 30 infrastructure controls and 11 release
safeguard tests pass.

This corrects offline release packaging. Live rollout rehearsal remains in
TASK-018 and depends on the confirmed staging target.
