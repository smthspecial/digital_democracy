## Finding

A configured verifier address is not an approved anonymous election protocol.
The current service can count frozen option identifiers; it does not implement
threshold encrypted tallying or receipt-freeness. Address/transport validation
alone must not enable these placeholder operations in a production process.

## Remediation

Production startup unconditionally blocks opening elections, issuing current
credentials, casting, tallying and certification in the voting service. The
cast handler returns 503 before contacting a verifier. There is no environment
switch to disable this gate while APP_ENV is production. Removal requires the
reviewed implementations and evidence from TASK-007 through TASK-012.

- [x] HTTP casting returns 503 without consulting a verifier.
- [x] Existing synthetic development elections still pass.
