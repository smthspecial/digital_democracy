## Description

As a platform-operator, I can see per-service reliability metrics against defined service-level objectives and receive automated alerts on error-budget burn, so that problems are caught before they affect citizens.

## Acceptance Criteria

- [ ] Each service has a published SLO with an error budget and burn-rate alerting
- [ ] Fast error-budget burn pages the on-call platform-operator; slow burn opens a tracked ticket
- [ ] SLO health dashboards are visible to the audit/oversight layer, not only to engineering
