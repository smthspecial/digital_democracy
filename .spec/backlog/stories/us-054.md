## Description

As a platform-operator, I can deploy, scale, and maintain the Kubernetes infrastructure so that the system stays available, without also being able to record ledger entries or report project milestones, so that no single credential controls both infrastructure and civic-financial governance.

## Acceptance Criteria

- [ ] The platform-operator credential is issued and revoked independently from the operator (civic-ledger) credential
- [ ] Any production-affecting infrastructure change requires a second independent platform-operator's real-time co-approval
- [ ] Every platform-operator action is recorded in the audit log

## Notes

- Realizes: FR-061, FR-067
- Technical aspects: AUTH-011, ADR-001, ARCH-003
- No single credential spans infrastructure control and civic-financial governance.
