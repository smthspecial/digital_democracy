## Description

As the system, I can require every internal service-to-service call to prove its identity cryptographically, so that a compromised component cannot impersonate another service or forge governance actions.

## Acceptance Criteria

- [ ] All internal service-to-service traffic is encrypted and authenticated via mutual TLS
- [ ] A service can only call the endpoints and produce/consume the queues explicitly declared for it in the system architecture; anything else is denied by default
- [ ] An internal call without a valid workload identity is rejected and logged as a security event

## Notes

- Realizes: NFR-007, NFR-008
- Technical aspects: AUTH-012, ADR-018, ARCH-005
- No forged internal calls; no impersonation of trusted services.
