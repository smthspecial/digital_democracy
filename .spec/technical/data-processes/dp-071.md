## Description

Given `{principal_ref, action, resource, context?}`, collects every `active` `policy_attachment` for that principal (including `role:operator`/`role:platform_operator` attachments, expanded by a live role-holder check against governance-role-service) and matches each attached policy's `actions`/`resources`/`conditions` against the request. Explicit `deny` always overrides a matching `allow`; no match is default-deny (ARCH-024 §4). Not itself audited (read-path traffic, unlike DP-069/070/072).
