## Description

Verifies the revoker holds an active `operator`, `platform_operator`, or `auditor` (AUTH-003) governance role (live check against governance-role-service). Unlike DP-069/070, no dual control is required — mirrors DP-068's grant/revoke asymmetry: pulling back access is always easier than granting it. Flips the target's status to `revoked` immediately. Emits to `audit.append`.
