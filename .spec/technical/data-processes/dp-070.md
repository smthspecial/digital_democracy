## Description

Verifies the endorser is a citizen distinct from the proposal's `proposed_by`, holding an active governance role of the same role_type (live check against governance-role-service) — modeled on DP-068's break-glass co-approval, not DP-035's three-layer approval (ARCH-024 §2: none of DP-035's approval types maps to the `implementation` layer operator/platform-operator roles occupy). Records a `policy_endorsement` row. An `approved` decision flips the target's status to `active`; a `rejected` decision flips it to `rejected`. Emits to `audit.append` either way.
