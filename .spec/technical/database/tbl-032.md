## Columns

| Column | Type | Description |
|--------|------|-------------|
| id | uuid | Primary key |
| citizen_id | uuid | Role holder |
| role_type | enum | auditor | reviewer | oversight | operator | platform_operator | review_body |
| layer | enum | protocol | implementation | audit | citizen |
| term_start | date | Term start |
| term_end | date | Term end (roles are time-limited) |
| randomized | boolean | Whether selected at random |

## Notes

Implements FR-062. Rotating, randomized, time-limited (ADR-009). `platform_operator` is a separate credential from `operator`: `operator` governs civic/ledger infrastructure (AUTH-006), `platform_operator` governs Kubernetes/cluster infrastructure (AUTH-011), so no single role holds both civic-ledger authority and cluster-admin authority (separation of duties per ADR-001).
