## Columns

| Column | Type | Description |
|--------|------|-------------|
| id | uuid | Primary key |
| target_type | enum | policy \| attachment |
| target_id | uuid | The `access_policy.id` or `policy_attachment.id` being endorsed |
| endorser_citizen_id | uuid | citizen_id of the endorsing operator/platform-operator (cross-service ref to identity-service citizen, not FK-enforced, ADR-015) |
| decision | enum | approved \| rejected |
| created_at | timestamptz | Endorsement time |

## Notes

Implements ADR-025/ARCH-024's dual-control grant flow (modeled on DP-068's break-glass co-approval, not DP-035's three-layer approval — see ARCH-024 §2 for why). One endorsement per citizen per target: `UNIQUE (target_type, target_id, endorser_citizen_id)`. The endorser must be a different citizen than the target's proposer, holding an active governance role of the same role_type — verified live against governance-role-service, not stored here. Publicly readable.
