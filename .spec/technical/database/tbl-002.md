## Columns

| Column | Type | Description |
|--------|------|-------------|
| id | uuid | Primary key |
| citizen_id | uuid | Verified citizen |
| method | enum | national_id | passport | gov_credential |
| evidence_ref | text | Encrypted reference to verification evidence |
| verified_at | timestamptz | When verification succeeded |
| status | enum | verified | rejected |

## Notes

Implements FR-002, FR-005. Verification events are auditable; evidence is encrypted, not public. A verification record is only ever created already-decided (the submitter supplies the outcome synchronously, per DP-002) — `citizen.status` (TBL-001), not this table, is what carries the citizen-level `pending` state before their first `verified` record activates them.
