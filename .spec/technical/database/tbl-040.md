## Columns

| Column | Type | Description |
|--------|------|-------------|
| id | uuid | Primary key |
| name | text | Human-readable policy name |
| effect | enum | allow \| deny |
| actions | text[] | Action strings this policy matches (e.g. `secrets:rotate`); a trailing `*` matches by prefix |
| resources | text[] | Resource strings this policy matches; same wildcard rule as actions |
| conditions | jsonb | Optional key/value conditions that must match the evaluation request's context; null means unconditional |
| description | text | Free-text explanation of intent |
| status | enum | pending_approval \| active \| rejected \| revoked |
| proposed_by | uuid | citizen_id of the operator/platform-operator who proposed this policy (cross-service ref to identity-service citizen, not FK-enforced, ADR-015) |
| created_at | timestamptz | Proposal time |

## Notes

Implements ADR-025/ARCH-024. Publicly readable (no hidden or exclusive grants, CON-005). Activates only via dual-control endorsement (TBL-042); explicit `deny` always overrides a matching `allow` at evaluation time.
