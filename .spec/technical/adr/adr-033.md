## Context

ADR-027 collapsed 18 services into two apps; tp-001..014 and arch-009..014 describe the pre-pivot topology and are increasingly wrong about current reality (per-service ports, seam-stub inventories, etc.) while still holding a real HP-N/EC-N scenario catalog worth keeping.

## Decision

A document whose factual claims no longer match the codebase is marked `status: deprecated` (superseded ADRs use `superseded`) rather than rewritten to match current reality. Its body is left as-is — a historical record of what was true when written — and a one-line header note is added: `> Historical: written pre-ADR-027 pivot (2026-09-08). Topology/seam claims below are stale; scenario catalog (HP-N/EC-N) still valid.` `.spec/AGENTS.md`'s Key Rules section references this convention.

## Consequences

tp-001..014, arch-009..014 get this header + status change (CC-11/CC-12). Their scenario ids remain citable from new Journey/E2E tests without anyone mistaking the topology prose for current.
