## Context

No code moves `Competency.status` off `applied` — the app's own tests seed active rows via the admin DB connection. No expiry/revalidation exists. `ConflictOfInterest`'s publication rule is undefined; `AUTH-010`'s `coi.none` condition currently reads as if disclosing a conflict bars publication, which disincentivizes disclosure.

## Decision

- **Grant validity (D23)**: flat 3 years, one named constant (`COMPETENCY_VALIDITY_YEARS`).
- **Review stage/quorum (D24)**: hybrid — domain peers review when ≥3 exist for the domain, an operator-role fallback otherwise (avoids deadlock on a new domain with no peers yet).
- **Public review period (D25)**: 14 days, advisory but mandatory to address — the approval's reasoning field must cite every objection raised; not a veto (FR-023's anti-veto stance).
- **COI and publication (D26)**: a disclosed conflict does NOT bar publication. `AUTH-010`'s `coi.none` condition and the code enforcing it are both changed: FR-025/TBL-014 describe disclosure-plus-publication, and a self-exclusion rule punishes honesty.
- **Inactivity (D27)**: no assessment or domain-scoped deliberation argument for 12 months costs active status; a warning fires at 10 months. Votes never count — coupling voting to expert standing violates FR-020's separation.
- **Challenge resolution (D28)**: `review_body` decides (matching `AUTH-010`'s `competency_appeal:decide`); an upheld challenge writes `status: revoked` and a reputation delta below `reputation.service.ts`'s `SIGNIFICANT_DELTA_THRESHOLD` for credential-based challenges only.
- **Level 0 (D29)**: implicit (no stored row) for every citizen with no competency record; `ApplyCompetencyDto` gets `@Min(1)`.
- **Revalidation depth (D30)**: abbreviated for levels 1–2 with a clean challenge record; full four-stage pipeline for levels 3–4 or anyone challenged in the expiring term.

## Consequences

E4-05 (pipeline substrate) through E4-19 (e2e) build against this; the acquisition pipeline's "stops at applied" gap (audit finding) closes via E4-05..E4-09, not by seeding through the admin connection.
